# JEM — Personal Portfolio

An interactive bilingual portfolio for crawler, data-cleaning, analysis, and visualization projects.

## Live sites

- Production: https://checkwhat.org
- GitHub Pages: https://guuu16.github.io

## Local development

```bash
npm ci
npm run dev
```

## Validation

```bash
npm run test:interactions
npm run test:sites
npm run build
```

The default language is English. Visitors can switch between English and Chinese from the site navigation.
